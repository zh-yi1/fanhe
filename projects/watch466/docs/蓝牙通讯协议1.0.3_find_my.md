## 协议详述

### 1. APP获取设备信息
#### APP请求
| 字段 | 长度（byte） | 说明 |
| ---- | ------------ | ---- |
| 帧头 | 2 | 0x55aa |
| 版本 | 1 | 0x00 |
| 消息标志 | 1 | 0x00 |
| 命令字 | 1 | 0x04 |
| 错误标志 | 1 | 执行错误的是否返回错误码 |
| 数据长度 | 2 | 0x00 |
| 数据 | xxxx |  |
| 校验和 | 1 | 从帧头开始按字节求和得出的结果对 256 求余 |

#### 设备返回
| 字段 | 长度（byte） | 说明 |
| ---- | ------------ | ---- |
| 帧头 | 2 | 0x55aa |
| 版本 | 1 | 0x00 |
| 消息标志 | 1 | 0x00 |
| 命令字 | 1 | 0x04 |
| 错误标志 | 1 | 执行错误的是否返回错误码 |
| 数据长度 | 2 | 6 |
| 数据 | xxxx | AA+BB+XXXX+YYYY |
| 校验和 | 1 | 从帧头开始按字节求和得出的结果对 256 求余 |

**数据说明**
1. 机型 AA
2. 彩屏/黑白 BB:
   - 02: 黑白屏
   - 04: 黑白红黄屏
   - 06: 黑白红黄蓝绿屏
   - 其他值: 未定义
3. 像素点
   - XXXX: X像素值，例：200 → 00C8
   - YYYY: Y像素值，例：200 → 00C8

| 字段 | 长度（byte） | 说明 |
| ---- | ------------ | ---- |
| 帧头 | 2 | 0x55aa |
| 版本 | 1 | 0x00 |
| 消息标志 | 1 | 0x00 |
| 命令字 | 1 | 0x01 |
| 错误标志 | 1 | 执行错误的是否返回错误码 |
| 数据长度 | 2 | 9 |
| 数据 | xxxx | AAAA+BBBB+CC+XXXX+YYYY |
| 校验和 | 1 | 从帧头开始按字节求和得出的结果对 256 求余 |

**数据说明**
- AAAA: 总长度
- BBBB: 拆分多少个包
- CC: 图片/个人信息

- XXXX*YYYY: 总像素点

### 3. 开始发送图片数据
#### APP发送
| 字段 | 长度（byte） | 说明 |
| ---- | ------------ | ---- |
| 帧头 | 2 | 0x55aa |
| 版本 | 1 | 0x00 |
| 消息标志 | 1 | 0x00 |
| 命令字 | 1 | 0x02 |
| 错误标志 | 1 | 执行错误的是否返回错误码 |
| 数据长度 | 2 | 2+sizeof(DATA) |
| 数据 | xxxx | AAAA+DATA |
| 校验和 | 1 | 从帧头开始按字节求和得出的结果对 256 求余 |

**说明**
1. AAAA: 帧序号
2. DATA: 帧数据
- 收到校验通过的数据不应答，加快传输速度
- 收到校验失败则回复失败的帧序号，APP需要从该序号开始重新往后继续发送

#### 设备返回
| 字段 | 长度（byte） | 说明 |
| ---- | ------------ | ---- |
| 帧头 | 2 | 0x55aa |
| 版本 | 1 | 0x00 |
| 消息标志 | 1 | 0x00 |
| 命令字 | 1 | 0x02 |
| 错误标志 | 1 | 执行错误的是否返回错误码 |
| 数据长度 | 2 |  |
| 数据 | xxxx | 校验成功：NULL；校验失败：失败的帧序号 |
| 校验和 | 1 | 从帧头开始按字节求和得出的结果对 256 求余 |
