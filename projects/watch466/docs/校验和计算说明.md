# 校验和计算说明

## 算法

从**帧头**开始到**数据区最后一字节**，逐字节累加，结果对 **256 取余**（取低 8 位）。

```
checksum = (byte[0] + byte[1] + ... + byte[N-1]) % 256
```

## 校验范围

```
┌──────┬──────┬──────┬──────────┬──────┬──────┬──────────┬──────────┬──────┐
│ 帧头  │ 帧头  │ 版本  │ 消息标志 │ 命令  │ 错误  │ 数据长度  │ 数据长度  │ 数据  │
│ 0x55 │ 0xAA │ ver  │ msg_flg │ cmd  │ err  │ dlen_H  │ dlen_L  │ ...  │
└──────┴──────┴──────┴──────────┴──────┴──────┴──────────┴──────────┴──────┘
  ←──────────────────── 累加范围 (不含校验和本身) ───────────────────→
```

**注意**：
- 校验和**不包括**自己
- 帧头 `0x55 0xAA` 也在校验范围内
- 数据区长度可变，但计算方式不变

## 示例 2：加热模块状态上报 (60字节帧)

```
55 AA 00 00 01 00 00 33
01 01 00 01 01 02 04 00 01 00 03 04 00 01 01 04 04 00 01 00
05 02 00 04 00 00 00 3C 06 02 00 04 00 00 00 00 07 04 00 01

```
帧头+版本+msg+cmd+err+dlen = 0x55+0xAA+0x00+0x00+0x01+0x00+0x00+0x33
                            = 85+170+0+0+1+0+0+51 = 307

DataPoints (51字节):
DP1:  01+01+00+01+01 = 4
DP2:  02+04+00+01+00 = 7
DP3:  03+04+00+01+01 = 9
DP4:  04+04+00+01+00 = 9

## C 代码实现

```c
/**
 * @brief 计算协议校验和
 *
 * 从 data[0] 到 data[len-1] 逐字节累加，结果对 256 取余（取低 8 位）。
 *
 * @param data  数据起始地址
 * @param len   数据字节数（不含校验和本身）
 * @return      校验和 (0x00 ~ 0xFF)
 */
static u8 lb_checksum(u8 *data, u16 len)
{
    u32 sum = 0;                        // u32 防累加上溢
    for (u16 i = 0; i < len; i++)
        sum += data[i];
    return (u8)(sum % 256);             // 取低 8 位
}
```

## 在线验证

遇到怀疑校验和不正确的帧，可以用这个快速验证：

```
帧长度 N 字节，最后 1 字节是收到的 checksum
计算前 N-1 字节的累加和 % 256
结果 == 收到的 checksum → 通过
结果 != 收到的 checksum → 数据损坏或计算错误
```

示例：帧 `55 AA 00 00 01 00 00 00 01`
- 校验范围前 8 字节：`55+AA+00+00+01+00+00+00 = 0x100`
- `0x100 % 256 = 0x00`
- 实际校验和 = `01`
- `0x00 ≠ 0x01` → 校验失败

正确帧：`55 AA 00 00 01 00 00 00 `**`00`**（校验和为 0x00）
