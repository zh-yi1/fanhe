# 指令解析手册

基于蓝牙通讯协议 v1.0.5 + MCU 通信协议 v1.0.7

---

## 1. 帧结构

```
┌──────┬──────┬──────┬──────────┬──────┬──────┬──────────┬──────────┬──────────┬──────┐
│ 帧头  │ 帧头  │ 版本  │ 消息标志 │ 命令  │ 错误  │ 数据长度  │ 数据长度  │   数据    │ 校验  │
│ 0x55 │ 0xAA │ 1B   │ 1B      │ 1B   │ 1B   │ (高8位)  │ (低8位)  │ 可变长度  │ 和   │
└──────┴──────┴──────┴──────────┴──────┴──────┴──────────┴──────────┴──────────┴──────┘
                                              ← 大端 (Big-Endian) →
```

| 字段 | 长度 | 说明 |
|:---|:---:|:---|
| 帧头 | 2B | 固定 `0x55 0xAA` |
| 版本 | 1B | 协议版本，当前 `0x00` |
| 消息标志 | 1B | 同步模式：请求=应答一致；异步模式：自增 |
| 命令字 | 1B | 见 [§2 命令字表](#2-命令字表) |
| 错误标志 | 1B | `0x00`=成功，`0x01`=执行异常 |
| 数据长度 | 2B | **大端**，数据区的字节数 |
| 数据 | 可变 | 见各命令详述 |
| 校验和 | 1B | 帧头→数据末尾累加 % 256 |

## 2. 命令字表

### 2.1 BLE 协议 (APP ↔ MCU, v1.0.5)

| 命令字 | 名称 | 方向 | 类型 |
|:---:|:---|:---|:---:|
| `0x01` | 查询产品信息 | APP→MCU→APP | 同步 |
| `0x02` | 查询动态属性 | APP→MCU→APP | 同步 |
| `0x03` | 状态上报 | MCU→APP | **异步** |
| `0x04` | 控制指令 | APP→MCU→APP | 同步 |
| `0x05` | 查询预约列表 | APP→MCU→APP | 同步 |
| `0x06` | 新增预约 | APP→MCU→APP | 同步 |
| `0x07` | 修改预约 | APP→MCU→APP | 同步 |
| `0x08` | 删除预约 | APP→MCU→APP | 同步 |
| `0x09` | 获取模式信息 | APP→MCU→APP | 同步 |
| `0x0A` | 修改模式信息 | APP→MCU→APP | 同步 |
| `0x0B` | 升级查询 | APP→MCU→APP | 同步 |
| `0x0C` | 升级启动 | APP→MCU→APP | 同步 |
| `0x0D` | 升级包传输 | APP→MCU→APP | 同步 |
| `0x0E` | 升级结束 | APP→MCU→APP | 同步 |

### 2.2 MCU UART 协议 (MCU ↔ 加热模块, v1.0.7)

| 命令字 | 名称 | 说明 |
|:---:|:---|:---|
| `0x01` | 动态属性 | 查询/控制/状态上报 |
| `0x02` | 查询预约列表 | APP→加热模块 |
| `0x03` | 预约操作 | 新增/修改/删除 |
| `0x04` | OTA 升级 | 升级包传输 |

### 2.3 桥模式 BLE ↔ UART 映射

| BLE 命令 | → | UART 命令 | 数据变换 |
|:---:|:---:|:---:|:---|
| `0x02` 查询动态属性 | → | `0x01` | 前拼 timestamp(4B) + sleep_flag(1B) |
| `0x04` 控制指令 | → | `0x01` | 前拼 timestamp(4B) + sleep_flag(1B) |
| `0x05` 查询预约列表 | → | `0x02` | 无数据，直接转发 |
| `0x06` 新增预约 | → | `0x03` | 前拼 action(1B) |
| `0x07` 修改预约 | → | `0x03` | 前拼 action(1B) |
| `0x08` 删除预约 | → | `0x03` | action=`0x00`，后跟 ID |
| `0x0B` 升级查询 | → | `0x04` | 透传 |

## 3. DataPoint 数据单元

### 3.1 格式

```
┌──────┬──────┬──────────┬──────────┬──────────┐
│ dpid │ type │  len_H   │  len_L   │  value   │
│ 1B   │ 1B   │ 1B      │ 1B      │ len 字节  │
└──────┴──────┴──────────┴──────────┴──────────┘
                       ← 大端 →
```

### 3.2 数据类型

| 类型 | 标识 | value 长度 | 说明 |
|:---|:---:|:---:|:---|
| `bool` | `0x01` | 1B | `0x00`=关，`0x01`=开 |
| `value` | `0x02` | 4B | 整型值，**大端** |
| `enum` | `0x04` | 1B | 枚举值 |

### 3.3 属性总表

| dpid | 名称 | 类型 | 值范围 |
|:---:|:---|:---:|:---|
| 1 | 总开关 | bool | `0`=关, `1`=开 |
| 2 | 加热模式 | enum | `0`=关, `1`=自定义, `2`=鸡腿, `3`=意面, `4`=预约, `5`=保温 |
| 3 | 电量 | enum | `1`=低, `2`=中, `3`=高, `4`=满 |
| 4 | 充电状态 | enum | `0`=未充, `1`=充电中, `2`=已充满 |
| 5 | 加热时长 | value | 30~210 分钟 (4B 大端) |
| 6 | 剩余时间 | value | 0~210 分钟 (4B 大端) |
| 7 | 加热温度 | enum | `0`=40°C ~ `5`=90°C, 每档+10°C |
| 8 | 语言 | enum | `0`=中文, `1`=英文, `2`=德语, `3`=法语, `4`=西语, `5`=意语, `6`=日语, `7`=俄语 |
| 9 | 故障提示 | enum | `0`=正常, `1`=高温告警 |
| 10 | 是否加热 | bool | `0`=停止, `1`=加热 |
| 11 | 时间戳 | value | Unix 时间戳 (仅 MCU UART) |

### 3.4 温度档位对照

| 档位 | 温度 | 华氏度(≈) |
|:---:|:---:|:---:|
| 0 | 40°C | 104°F |
| 1 | 50°C | 122°F |
| 2 | 60°C | 140°F |
| 3 | 70°C | 158°F |
| 4 | 80°C | 176°F |
| 5 | 90°C | 194°F |

## 4. 帧解析示例

### 4.1 BLE 控制指令：启动加热 (32字节)

```
55 AA 00 00 04 00 00 17
02 04 00 01 03
05 02 00 04 00 00 00 3C
07 04 00 01 05
0A 01 00 01 01
89
```

| 字段 | 值 | 说明 |
|:---|:---|:---|
| 帧头 | `55 AA` | 协议帧起始标志 |
| 版本 | `00` | 协议版本 0 |
| 消息标志 | `00` | 请求序号 0 |
| 命令字 | `04` | **控制指令** (BLE) |
| 错误标志 | `00` | 正常 |
| 数据长度 | `00 17` | = 23 字节 (大端) |
| | | |
| **DataPoint 1** | | |
| dpid | `02` | 加热模式 |
| type | `04` | enum |
| len | `00 01` | = 1 字节 |
| value | `03` | **意面模式** |
| | | |
| **DataPoint 2** | | |
| dpid | `05` | 加热时长 |
| type | `02` | value |
| len | `00 04` | = 4 字节 |
| value | `00 00 00 3C` | = **60 分钟** (大端) |
| | | |
| **DataPoint 3** | | |
| dpid | `07` | 加热温度 |
| type | `04` | enum |
| len | `00 01` | = 1 字节 |
| value | `05` | **90°C** |
| | | |
| **DataPoint 4** | | |
| dpid | `0A` | 是否加热 |
| type | `01` | bool |
| len | `00 01` | = 1 字节 |
| value | `01` | **加热=开** |
| | | |
| 校验和 | `89` | `(85+170+4+23+所有DataPoint) % 256` |

### 4.2 桥模式翻译：BLE → UART (37字节)

```
55 AA 00 0C 01 00 00 1C
0C 01 C1 BB   ← timestamp (4B, 大端)
01            ← sleep_flag (MCU 使能开机)
02 04 00 01 03   ← DataPoint: 模式=意面(3)
05 02 00 04 00 00 00 3C   ← DataPoint: 时长=60分钟
07 04 00 01 05   ← DataPoint: 温度=90°C
0A 01 00 01 01   ← DataPoint: 加热=开
15
```

| 对比 BLE 帧 | 变化 |
|:---|:---|
| 命令字 | `04` → **`01`** (控制指令 → 动态属性) |
| 数据长度 | `0x17`(23) → **`0x1C`**(28) = 多了 5 字节 |
| 数据区 | 前拼 **timestamp** (4B BE) + **sleep_flag** (1B=`0x01`)，后跟 DataPoints 透传 |

### 4.3 加热模块状态上报 (60字节)

```
55 AA 00 00 01 00 00 33
  01 01 00 01 01    ← DP1: 总开关=开
  02 04 00 01 00    ← DP2: 模式=关闭
  03 04 00 01 01    ← DP3: 电量=低
  04 04 00 01 00    ← DP4: 充电=未充电
  05 02 00 04 00 00 00 3C  ← DP5: 加热时长=60分钟
  06 02 00 04 00 00 00 00  ← DP6: 剩余时间=0
  07 04 00 01 02    ← DP7: 温度=60°C
  09 04 00 01 00    ← DP9: 故障=正常
  0A 01 00 01 00    ← DP10: 加热=否
  CB
```

### 逐字段拆解

```
55 AA            帧头
00               版本 = 0
00               消息标志 = 0
01               命令字 = 0x01 (动态属性)
00               错误标志 = 正常
00 33            数据长度 = 51 字节 (0x0033, 大端)

─── DataPoint 1: 总开关 ───
01               dpid = 1 (总开关)
01               type = bool
00 01            len = 1
01               value = 1 (开)

─── DataPoint 2: 加热模式 ───
02               dpid = 2 (加热模式)
04               type = enum
00 01            len = 1
00               value = 0 (关闭)

─── DataPoint 3: 电量 ───
03               dpid = 3 (电量)
04               type = enum
00 01            len = 1
01               value = 1 (低电量)

─── DataPoint 4: 充电状态 ───
04               dpid = 4 (充电状态)
04               type = enum
00 01            len = 1
00               value = 0 (未充电)

─── DataPoint 5: 加热时长 ───
05               dpid = 5 (加热时长)
02               type = value (4B整型)
00 04            len = 4
00 00 00 3C      value = 0x0000003C = 60 分钟 (大端)

─── DataPoint 6: 剩余加热时间 ───
06               dpid = 6 (剩余时间)
02               type = value
00 04            len = 4
00 00 00 00      value = 0 分钟 (加热已完成/未启动)

─── DataPoint 7: 加热温度 ───
07               dpid = 7 (加热温度)
04               type = enum
00 01            len = 1
02               value = 2 → 60°C

─── DataPoint 9: 故障提示 ───
09               dpid = 9 (故障提示)
04               type = enum
00 01            len = 1
00               value = 0 (正常)

─── DataPoint 10: 是否加热 ───
0A               dpid = 10 (是否加热)
01               type = bool
00 01            len = 1
00               value = 0 (停止加热)

CB               校验和
   校验: 0x55+0xAA+0x00+0x00+0x01+0x00+0x00+0x33
         + (所有DataPoint字节)
         = 459 → 459 % 256 = 203 = 0xCB ✓
```


### 4.7 状态上报 (BLE 0x03, 异步)

**加热完成** (12字节)：
```
55 AA 00 00 03 00 00 06 06 02 00 04 00 00 00 00 14
```

| 字段 | 值 | 说明 |
|:---|:---|:---|
| 命令字 | `03` | 状态上报 (异步) |
| 数据长度 | `00 06` | 6 字节 |
| data[0] | `06` | dpid=6 (剩余时间) |
| data[1] | `02` | type=value |
| data[2-3] | `00 04` | len=4 |
| data[4-7] | `00 00 00 00` | 剩余时间=0 (加热完成) |
| 校验和 | `14` | |

**故障高温告警** (11字节)：
```
55 AA 00 00 03 00 00 04 09 04 00 01 01 15
```

| 字段 | 值 | 说明 |
|:---|:---|:---|
| data[0] | `09` | dpid=9 (故障) |
| data[1] | `04` | type=enum |

| data[4] | `01` | value=1 (**高温告警**) |

## 5. 预约帧结构

### 5.1 BLE 预约 (41B payload)

```
┌──────┬───────────────┬──────────┬──────┬──────────┬──────────┬──────────┐
│  ID  │     name      │  time    │ temp │ duration │ enabled  │  repeat  │
│ 1B   │     32B       │ 4B (BE)  │ 1B   │   1B     │   1B     │   1B     │
└──────┴───────────────┴──────────┴──────┴──────────┴──────────┴──────────┘
```

### 5.2 重复周期位掩码

| Bit | 日期 | 值=0x3E(工作日) |
|:---:|:---|:---:|
| bit0 | 周日 | 0 |
| bit1 | 周一 | 1 |
| bit2 | 周二 | 1 |
| bit3 | 周三 | 1 |
| bit4 | 周四 | 1 |
| bit5 | 周五 | 1 |
| bit6 | 周六 | 0 |
| bit7 | 保留 | 0 |

常用值：`0xFF`=每天，`0x3E`=周一至周五，`0x41`=周末，`0x20`=周五。

## 6. 桥模式数据流总结

```
  APP (手机)
    │  BLE Write (cmd=0x04, DataPoints)
    ▼
  MCU (AB5790)
    │ lb_translate_ble_to_uart()
    │ cmd: 0x04→0x01
    │ data: 前拼 timestamp+sleep_flag
    ▼
  加热模块
    │ UART RX → 处理 → UART TX
    │ cmd=0x01, DataPoints (全量状态)
    ▼
  MCU (AB5790)
    │ lb_translate_uart_to_ble()
    │ cmd: 0x01→0x04
    │ data: 去掉 timestamp+sleep_flag
    ▼
  APP (手机)
    BLE Notify (cmd=0x04, DataPoints 应答)
```
