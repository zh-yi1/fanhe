============================================================
  OTA 固件打包工具 — 蓝牙饭盒 (BLEDebug 专用)
============================================================

功能: 将 MCU 固件 (.fot) 或加热模块固件 (.bin) 打包为 BLE OTA 升级帧文件 (.ota)，
      可直接通过 BLEDebug 工具逐帧发送。

协议: 蓝牙通讯协议 v1.0.8 §5 (CMD 0x0C/0x0D/0x0E)
      数据区包含 256 字节 BIN 包头 (magic=0x11223344, CRC32/MPEG-2)。

------------------------------------------------------------
用法
------------------------------------------------------------

  打包主单片机固件:
    node ota_packer.js mcu --input <file.fot> [--version <ver>] [--output <file.ota>]

  打包加热模块固件:
    node ota_packer.js heat --input <file.bin> [--version <ver>] [--output <file.ota>]

  解析已有 .ota 文件:
    node ota_packer.js parse --input <file.ota>

------------------------------------------------------------
参数
------------------------------------------------------------

  --input, -input, -i <file>    输入固件文件路径 (必需)
  --output, -output, -o <file>  输出 .ota 文件路径 (可选)
  --version, -version, -v <ver> 固件版本号 (可选, 默认 0x00000001)
  --help, -help, -h             显示帮助信息

------------------------------------------------------------
版本号格式
------------------------------------------------------------

  支持四种格式:
    十六进制:  0x00010000
    十进制:    65536
    点分:      1.0.0  (对应 major.minor.patch → 0x01000000)
    ASCII:     v005   (转为 4 字节 ASCII, 不足补 0x00)

------------------------------------------------------------
输出目录 (默认, 未指定 --output 时)
------------------------------------------------------------

  MCU  → Output/bin/ota_dog/mcu_ota/
  Heat → Output/bin/ota_dog/heat_ota/

------------------------------------------------------------
示例
------------------------------------------------------------

  # 加热模块: 最基本的用法
  node ota_packer.js heat --input otah_Project_v005.bin

  # 加热模块: 使用绝对路径
  node ota_packer.js heat --input "C:\Users\31017\Desktop\Liu Wei-tool\otah_Project_v005.bin"

  # 加热模块: 指定版本号 v005
  node ota_packer.js heat --input otah_Project_v005.bin --version v005

  # 加热模块: 指定输出路径
  node ota_packer.js heat --input fw.bin --version 1.0.0 --output my_fw.ota

  # 主单片机
  node ota_packer.js mcu --input test_ota.fot

  # 解析 .ota 文件查看帧结构
  node ota_packer.js parse --input output.ota

------------------------------------------------------------
打包流程
------------------------------------------------------------

  1. 构建 256 字节 BIN 包头 (magic + version + fw_len + CRC32/MPEG-2)
  2. 包头 + 固件 → 完整 BIN 数据
  3. BIN 数据按 128 字节分包 (16 字节对齐)
  4. 生成帧序列: 1×START(0x0C) + N×DATA(0x0D) + 1×END(0x0E)

------------------------------------------------------------
帧结构
------------------------------------------------------------

  每帧格式 (蓝牙通讯协议 v1.0.8 §2.1):
    帧头(2B) + 版本(1B) + 消息标志(1B) + 命令字(1B) + 错误标志(1B)
    + 数据长度(2B, 大端) + 数据(可变) + 校验和(1B)

  校验和: 所有字节求和 mod 256

------------------------------------------------------------
BIN 包头结构 (256 字节)
------------------------------------------------------------

  字节 0-3:   Magic 0x11223344 (大端)
  字节 4-7:   固件版本号 (大端)
  字节 8-11:  固件内容总长度, 不含头部 (大端)
  字节 12-15: 固件 CRC32/MPEG-2 校验码 (大端)
  字节 16-255: 填充 0xFF
